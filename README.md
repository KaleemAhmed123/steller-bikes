# Raju Cycles

Online store **and** owner back-office for a cycle shop in Kanpur, UP, India. A rebuild of the v1
prototype onto a maintainable stack — **Next.js (frontend) + Node/Express + MongoDB** — carrying over
its proven design.

**The one idea:** *the server is the authority on price and stock; the admin is permission-gated;
build the least that works.*

Full docs: [`docs/specs/storefront-rebuild/`](docs/specs/storefront-rebuild/) — context, decisions,
and the scaffold plan. Rules for how we work: [`CLAUDE.md`](CLAUDE.md). Commands:
[`playbook.md`](playbook.md).
